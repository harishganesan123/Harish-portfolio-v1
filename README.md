# Harish G — Portfolio

A fast, responsive React + Vite personal portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite (normally http://localhost:5173).

## Build

```bash
npm run build
```

## Deploy

Push this folder to GitHub and import the repository into Vercel.

## Before publishing

- Replace `public/Harish_Resume.pdf` if you update your resume.
- Update project links in `src/main.jsx` if each project gets its own repository.
- Add a profile photo later if desired.
